# نطّة السطوح · Natta El Sotouh

A cartoon endless jumper: bounce up a Cairo apartment building with **Mar3y**, a white cat with one amber and one blue eye, past balconies, AC units, pigeons and flying slippers, up to the rooftops and the sky.

**Play now: https://mfathy234.github.io/natta-el-sotouh-releases/play/**

- Website (Arabic): https://mfathy234.github.io/natta-el-sotouh-releases/
- Website (English): https://mfathy234.github.io/natta-el-sotouh-releases/en/
- Free, no account, plays offline, installable as an app (PWA). Android APK coming soon.

This repository holds the public site (`index.html`, `en/`, `assets/`) and the web build of the game (`play/`). The game source is private. All characters, names and drawings are original.
